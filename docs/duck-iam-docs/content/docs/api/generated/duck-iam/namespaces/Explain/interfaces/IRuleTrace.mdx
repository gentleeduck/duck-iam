Trace of a single rule: action / resource / condition match status, plus the conditions tree.

## Example

```ts
const rule: Explain.IRuleTrace = {
  ruleId: 'admin-can-write',
  effect: 'allow',
  priority: 100,
  actionMatch: true,
  resourceMatch: true,
  conditionsMet: true,
  conditions: group,
  matched: true,
}
```
