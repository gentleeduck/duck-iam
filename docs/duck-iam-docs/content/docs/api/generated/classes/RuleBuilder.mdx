Chainable builder for an [AccessControl.IRule](../duck-iam/namespaces/AccessControl/interfaces/IRule): an effect, the actions and resources it covers,
an optional scope and a condition tree. Its `PolicyBuilder`'s algorithm resolves conflicts.

## Example

```ts
import { defineRule } from '@gentleduck/iam'

const rule = defineRule('post.update.owner')
  .allow()
  .desc('Authors may update their own posts')
  .priority(20)
  .on('update')
  .of('post')
  .when(w => w.isOwner())
  .build()
```
