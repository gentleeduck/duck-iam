Chainable builder for an [AccessControl.IRole](../duck-iam/namespaces/AccessControl/interfaces/IRole): permissions plus optional parent roles.
`rolesToPolicy()` turns roles into ABAC rules, so RBAC and ABAC share one engine.

## Example

```ts
import { defineRole } from '@gentleduck/iam'

const editor = defineRole('editor')
  .name('Editor')
  .desc('Full write access to posts and comments')
  .inherits('viewer')
  .grant('create', 'post')
  .grant('update', 'post')
  .grant('delete', 'post')
  .grantCRUD('comment')
  .build()
```
