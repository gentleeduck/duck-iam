### withTransaction()

> **withTransaction**(`client`: `unknown`): [`IamEngine`](../duck-iam/namespaces/Bound/interfaces/IamEngine)\<`TAction`, `TResource`, `TRole`, `TScope`, `TMode`\>

Defined in: [packages/duck-iam/src/core/engine/engine.ts:1291](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-iam/src/core/engine/engine.ts#L1291)

A view whose adapter runs on the transaction handle `client` and whose invalidations buffer into `pending`.
Reads use empty caches, so they see the transaction's own writes.

```ts
let pending
await db.transaction(async (tx) => {
  const perms = iam.withTransaction(tx)
  await perms.admin.assignRole(userId, 'admin', orgId)
  await tx.insert(members).values({ userId, orgId })
  pending = perms.pending
})
await pending.flush() // invalidate and broadcast only after the commit
```

A rollback needs no cleanup; `pending.discard()` says so explicitly.

#### Parameters

##### client

`unknown`

Opaque driver handle, passed straight to the adapter.

#### Returns

[`IamEngine`](../duck-iam/namespaces/Bound/interfaces/IamEngine)\<`TAction`, `TResource`, `TRole`, `TScope`, `TMode`\>

#### Throws

When the adapter has no `withClient`, rather than writing outside the transaction.
