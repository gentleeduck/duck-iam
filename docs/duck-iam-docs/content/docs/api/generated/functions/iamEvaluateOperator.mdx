Applies one raw operator to two already-resolved operands, for linters and condition previews.
SECURITY: has none of `evalCondition`'s guards (`$`-pattern refusal, operand types); never use it to decide access.

## Parameters

### op

[`Operator`](../duck-iam/namespaces/AccessControl/type-aliases/Operator)

The operator to apply.

### fieldValue

[`AttributeValue`](../duck-iam/namespaces/IamPrimitives/type-aliases/AttributeValue)

Left-hand side, already resolved from the request.

### condValue

[`AttributeValue`](../duck-iam/namespaces/IamPrimitives/type-aliases/AttributeValue)

Right-hand side, already resolved.

## Returns

`boolean`

## Throws

When `op` is not one of `ops`' own keys, so a linter cannot report an inherited name as satisfied.
