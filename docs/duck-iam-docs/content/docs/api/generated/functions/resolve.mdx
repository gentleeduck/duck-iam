Resolves a dot-path field against an [IamRequest.IAccessRequest](../duck-iam/namespaces/IamRequest/interfaces/IAccessRequest).
SECURITY: reads own properties only, so nothing on the prototype chain is reachable.

## Parameters

### request

[`IAccessRequest`](../duck-iam/namespaces/IamRequest/interfaces/IAccessRequest)

The access request providing root data.

### path

`string`

Dot-path starting with an allowed root, or the `action` / `scope` shorthand.

### caches?

Optional per-Engine path-segment cache; falls back to the module-global one.

`Map`\<`string`, `string`[] \| `null`\>

[`AttributeValue`](../duck-iam/namespaces/IamPrimitives/type-aliases/AttributeValue)
