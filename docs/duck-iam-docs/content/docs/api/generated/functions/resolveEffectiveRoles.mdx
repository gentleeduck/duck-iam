> **resolveEffectiveRoles**(`assignedRoles`: `string`[], `allRoles`: [`IRole`](../duck-iam/namespaces/AccessControl/interfaces/IRole)\<`string`, `string`, `string`, `string`\>[], `reportUndefinedAssigned?`: (`roleId`: `string`) => `void`): `string`[]

Defined in: [packages/duck-iam/src/core/rbac/rbac.ts:138](https://github.com/gentleeduck/duck-iam/blob/7473829ff0a699673ccc14cb16b69c82ac668263/packages/duck-iam/src/core/rbac/rbac.ts#L138)

Walk `inherits` from each assigned role into the closed set of effective role IDs, bounded by
[MAX\_INHERITANCE\_DEPTH](../variables/MAX_INHERITANCE_DEPTH). Inherited IDs with no definition are dropped; assigned IDs are kept.

## Parameters

### assignedRoles

`string`[]

Role IDs directly assigned to the subject.

### allRoles

[`IRole`](../duck-iam/namespaces/AccessControl/interfaces/IRole)\<`string`, `string`, `string`, `string`\>[]

Every role definition, used to resolve `inherits`.

### reportUndefinedAssigned?

(`roleId`: `string`) => `void`

Called with an assigned ID no role defines. Kept as an effective role, but its
  `inherits` cannot be walked, so every role it would have conferred is absent with nothing else to show it.

## Returns

`string`[]

Closed set of effective role IDs (assigned + defined inherited).
