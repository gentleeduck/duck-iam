> **rolesToPolicy**(`roles`: [`IRole`](../duck-iam/namespaces/AccessControl/interfaces/IRole)\<`string`, `string`, `string`, `string`\>[], `scopeMode?`: `"flat"` \| `"hierarchical"`): [`IPolicy`](../duck-iam/namespaces/AccessControl/interfaces/IPolicy)

Defined in: [packages/duck-iam/src/core/rbac/rbac.ts:63](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-iam/src/core/rbac/rbac.ts#L63)

Convert RBAC roles into an ABAC policy: each permission becomes a rule gated on `subject.roles` containing the role.

## Parameters

### roles

[`IRole`](../duck-iam/namespaces/AccessControl/interfaces/IRole)\<`string`, `string`, `string`, `string`\>[]

Every role definition.

### scopeMode?

`"flat"` \| `"hierarchical"`

`IConfig.scopeMode`: `'hierarchical'` lets a role-declared scope cover its descendants, as it
                   does for assignments; `'flat'` (default) needs an exact match.

## Returns

[`IPolicy`](../duck-iam/namespaces/AccessControl/interfaces/IPolicy)

A synthetic [AccessControl.IPolicy](../duck-iam/namespaces/AccessControl/interfaces/IPolicy) with one allow rule per permission.
