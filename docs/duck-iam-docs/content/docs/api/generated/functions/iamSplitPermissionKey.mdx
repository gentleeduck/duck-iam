> **iamSplitPermissionKey**(`key`: `string`): `string`[]

Defined in: [packages/duck-iam/src/shared/keys.ts:58](https://github.com/gentleeduck/duck-iam/blob/7473829ff0a699673ccc14cb16b69c82ac668263/packages/duck-iam/src/shared/keys.ts#L58)

Splits a key from [iamBuildPermissionKey](iamBuildPermissionKey) into unescaped segments, honouring `\:`, `\\` and `\@`.
A scoped key's leading `@` is not stripped; use [iamParsePermissionKey](iamParsePermissionKey) for that.

## Parameters

### key

`string`

Permission key, e.g. `'read:document'` or `'write:doc\\:42'`.

## Returns

`string`[]
