### clockSkewSec?

> `optional` **clockSkewSec?**: `number`

Defined in: [packages/duck-auth/src/core/transport/jwt.transport.ts:50](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/core/transport/jwt.transport.ts#L50)

Seconds of leeway on `exp` and `abs`, for instances that disagree on the time. Default 0.
 WARN: it widens the window an expired token is accepted in. The forward bound on `iat` allows a
 fixed 60s on top of this.

### freshnessMs?

> `optional` **freshnessMs?**: `number`

Defined in: [packages/duck-auth/src/core/transport/jwt.transport.ts:46](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/core/transport/jwt.transport.ts#L46)

Freshness window in ms: a round trip reconstructs the session with
 `fresh = (now - rotatedAt) < freshnessMs`. Default 5 minutes, matching `Sessions.Cfg`.
 WARN: privileged operations branch on `fresh`, so too high a value disables the gate.

### refresh?

Defined in: [packages/duck-auth/src/core/transport/jwt.transport.ts:52](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/core/transport/jwt.transport.ts#L52)

Optional refresh cookie shape.

#### cookieName?

> `optional` **cookieName?**: `string`

Cookie name carrying the opaque refresh token.

#### sameSite?

> `optional` **sameSite?**: `"strict"` \| `"lax"` \| `"none"`

Default `'strict'`; `'lax'` for a refresh endpoint reached by a top-level navigation.
 WARN: `'none'` sends this cookie, which carries the plaintext SID, on every cross-site
 request. An SPA on a different origin to its API needs it; nothing else does.

#### ttlMs?

> `optional` **ttlMs?**: `number`

Refresh TTL in ms. Default 7 days.

***
