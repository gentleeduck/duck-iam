### freshnessMs?

> `optional` **freshnessMs?**: `number`

Defined in: [packages/duck-auth/src/core/transport/jwt.transport.ts:47](https://github.com/gentleeduck/duck-iam/blob/7b68e272765f6b233d7451837d0df2fdbddd0658/packages/duck-auth/src/core/transport/jwt.transport.ts#L47)

Freshness window in ms: a round trip reconstructs the session with

### refresh?

> `optional` **refresh?**: \{ `cookieName?`: `string`; `sameSite?`: `"strict"` \| `"lax"` \| `"none"`; `ttlMs?`: `number`; \}

Defined in: [packages/duck-auth/src/core/transport/jwt.transport.ts:53](https://github.com/gentleeduck/duck-iam/blob/7b68e272765f6b233d7451837d0df2fdbddd0658/packages/duck-auth/src/core/transport/jwt.transport.ts#L53)

Optional refresh cookie shape.

#### cookieName?

> `optional` **cookieName?**: `string`

Cookie name carrying the opaque refresh token. Default `__Host-duck-refresh`, which outside
 production drops its prefix along with Secure; read it back by `refreshCookieName`.

#### sameSite?

> `optional` **sameSite?**: `"strict"` \| `"lax"` \| `"none"`

Default `'strict'`; `'lax'` for a refresh endpoint reached by a top-level navigation.
 WARN: `'none'` sends this cookie, which carries the plaintext SID, on every cross-site
 request. An SPA on a different origin to its API needs it; nothing else does.

#### ttlMs?

> `optional` **ttlMs?**: `number`

Refresh TTL in ms. Default 7 days.

***
