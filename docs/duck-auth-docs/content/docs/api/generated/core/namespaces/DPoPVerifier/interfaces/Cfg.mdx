### expectedNonce?

> `optional` **expectedNonce?**: `string` \| (() => `string` \| `Promise`\<`string`\>)

Defined in: [packages/duck-auth/src/core/transport/dpop.transport.ts:51](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/core/transport/dpop.transport.ts#L51)
