### expectedHostname?

> `optional` **expectedHostname?**: `string` \| `string`[]

Defined in: [packages/duck-auth/src/core/captcha/captcha.types.ts:68](https://github.com/gentleeduck/duck-iam/blob/7b68e272765f6b233d7451837d0df2fdbddd0658/packages/duck-auth/src/core/captcha/captcha.types.ts#L68)

Host the widget is expected to have run on, bare, as the provider reports it: `app.example.com`. Unset
 means the result reports it unchecked. Compared case-insensitively, since a hostname is.
