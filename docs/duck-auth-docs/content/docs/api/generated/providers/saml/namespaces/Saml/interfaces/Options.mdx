### allowReplay?

> `optional` **allowReplay?**: `boolean`

Defined in: [packages/duck-auth/src/providers/saml/saml.types.ts:82](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/providers/saml/saml.types.ts#L82)

Accepts responses with no replay protection at all. Default false: without a store one captured
 POST body mints a fresh session on every repeat, for as long as the assertion's own
 `NotOnOrAfter` window lasts, which node-saml's `acceptedClockSkewMs` widens.

### replayStore?

> `optional` **replayStore?**: \{ `consume`: (`assertionId`: `string`) => `Promise`\<`boolean`\>; \}

Defined in: [packages/duck-auth/src/providers/saml/saml.types.ts:78](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/providers/saml/saml.types.ts#L78)

Consumes an assertion id exactly once, answering false when it has been seen.
 SECURITY: the only replay protection this wrapper requires. The client's InResponseTo cache is
 neither configured nor mandatory here, so without this one captured POST body mints a fresh session
 per repeat.

### verifyRelayState?

> `optional` **verifyRelayState?**: (`input`: \{ `relayState`: `string`; `tenantId?`: `string`; \}) => `Promise`\<`boolean`\>

Defined in: [packages/duck-auth/src/providers/saml/saml.types.ts:70](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/providers/saml/saml.types.ts#L70)
