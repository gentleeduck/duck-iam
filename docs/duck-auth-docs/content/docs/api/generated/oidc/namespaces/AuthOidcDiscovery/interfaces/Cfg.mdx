### allowHttp?

> `optional` **allowHttp?**: `boolean`

Defined in: [packages/duck-auth/src/oidc/index.ts:274](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/oidc/index.ts#L274)

Permit a non-HTTPS `issuer`. Dev-only. OIDC core section 16.18 requires
HTTPS in production. Default false; explicit opt-in here so the
misconfig is visible in code review.

***

### extraClaims?

> `optional` **extraClaims?**: `Record`\<`string`, `unknown`\>

Defined in: [packages/duck-auth/src/oidc/index.ts:281](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/oidc/index.ts#L281)

Extra fields merged at the top level (for OIDC profiles or
extensions). Spread BEFORE the canonical fields so a misconfigured
caller cannot shadow `issuer`, `jwks_uri`, `token_endpoint`, etc.
via this hatch.
