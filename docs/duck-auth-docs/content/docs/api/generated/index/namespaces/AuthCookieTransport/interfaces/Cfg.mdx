### maxAgeSec?

> `optional` **maxAgeSec?**: `number`

Defined in: [packages/duck-auth/src/core/transport/cookie.transport.ts:24](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/core/transport/cookie.transport.ts#L24)

A positive whole number of seconds, to end the cookie before the session does. Unset, it lives to
 `Sessions.Me.absoluteExpiresAt`, so a session `resolveSession` slides keeps its cookie; the idle
 deadline is server-side, in `isSessionExpired`.

***

### name?

> `optional` **name?**: `string`

Defined in: [packages/duck-auth/src/core/transport/cookie.transport.ts:11](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/core/transport/cookie.transport.ts#L11)

`__Host-duck-sid` when no `domain` is set, which is the prefix browsers enforce Secure, `Path=/`
 and no Domain for; `duck-sid` otherwise.

### secure?
