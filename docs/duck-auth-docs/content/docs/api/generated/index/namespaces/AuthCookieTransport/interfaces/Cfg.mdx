### maxAgeSec?

> `optional` **maxAgeSec?**: `number`

Defined in: [packages/duck-auth/src/core/transport/cookie.transport.ts:22](https://github.com/gentleeduck/duck-iam/blob/7b68e272765f6b233d7451837d0df2fdbddd0658/packages/duck-auth/src/core/transport/cookie.transport.ts#L22)

A positive whole number of seconds, to end the cookie before the session does. Unset, it lives to
 `Sessions.Me.absoluteExpiresAt`, so a session `resolveSession` slides keeps its cookie; the idle
 deadline is server-side, in `isSessionExpired`.

***

### name?

> `optional` **name?**: `string`

Defined in: [packages/duck-auth/src/core/transport/cookie.transport.ts:12](https://github.com/gentleeduck/duck-iam/blob/7b68e272765f6b233d7451837d0df2fdbddd0658/packages/duck-auth/src/core/transport/cookie.transport.ts#L12)

`__Host-duck-sid` when no `domain` is set, which is the prefix browsers enforce Secure, `Path=/`
 and no Domain for; `duck-sid` otherwise. Outside production the prefix is dropped with Secure.
