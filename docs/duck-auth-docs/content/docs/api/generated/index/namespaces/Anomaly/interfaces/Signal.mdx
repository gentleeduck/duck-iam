### evidence

Defined in: [packages/duck-auth/src/core/anomaly/anomaly.types.ts:17](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/core/anomaly/anomaly.types.ts#L17)

What a human reading the audit record needs. It reaches every `suspicious` sink, so it carries
 derived values - a fingerprint, a distance - never the address, header or position behind them.
