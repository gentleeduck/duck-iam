### reactions?

> `optional` **reactions?**: `Record`\<`string`, `Record`\<`string`, [`Decision`](Decision)\>\>

Defined in: [packages/duck-auth/src/core/anomaly/anomaly.types.ts:68](https://github.com/gentleeduck/duck-iam/blob/c55c8b5f940145dfa5045794816563fec354e516/packages/duck-auth/src/core/anomaly/anomaly.types.ts#L68)

Overrides by detector id, then kind, with `'*'` for any detector. `'allow'` mutes the signal;
`'step-up'` or `'deny'` forces at least that decision whatever it scored.
NOTE: nested because kinds are open - a flat `id#kind` key could be forged by a kind holding `#`.
