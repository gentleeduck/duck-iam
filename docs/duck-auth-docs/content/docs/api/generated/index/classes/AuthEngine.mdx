## Methods

### resolveSession()

> **resolveSession**(`req`: \{ `headers`: `Headers`; \}, `opts?`: \{ `allTenants?`: `true`; `expectedTenantId?`: `string`; `requestSnapshot?`: [`RequestSnapshot`](../namespaces/Anomaly/interfaces/RequestSnapshot); \}): [`Me`](../namespaces/Answer/interfaces/Me)\<[`ResolveResult`](../namespaces/Engine/type-aliases/ResolveResult)\<`Profile`\>\>

Defined in: [packages/duck-auth/src/core/engine/engine.ts:210](https://github.com/gentleeduck/duck-iam/blob/7b68e272765f6b233d7451837d0df2fdbddd0658/packages/duck-auth/src/core/engine/engine.ts#L210)

The current session, verified statelessly where the transport can and otherwise read from
 `Sessions.Store`. Rejects `AUTH_SESSION_REVOKED` where the request carries no token or it matches no
 live session, which `orNull()` reads back as null - and `AUTH_SESSION_IDENTITY_ERASED`, which it does
 not, so a session outliving its identity stays loud however this is read.

#### Parameters

##### req

###### headers

`Headers`

##### opts?

###### allTenants?

`true`

Accepts the session in whatever tenant it is, over `expectedTenantId`, for a check that grants nothing,
 as CSRF's does.

###### expectedTenantId?

`string`

The tenant the session must belong to; naming none accepts only a session with no tenant.

###### requestSnapshot?

[`RequestSnapshot`](../namespaces/Anomaly/interfaces/RequestSnapshot)

### strict()

> **strict**(`opts?`: \{ `compliance?`: `Partial`\<[`Wired`](../namespaces/Compliance/type-aliases/Wired)\>; \}): `void`

Boot-time checks, throwing `AUTH_MISCONFIGURED` on any production footgun when `NODE_ENV` is production or
 unset, and on a compliance preset's gaps in every environment. Its event checks see only the handlers
 registered before it runs, so call it after every `on()` and `use()`.

Install a plugin: its event handlers, its facet under `plugins.facets[id]`, its `install` hook,
 then its providers. All of it or none of it - providers go last because registering one cannot be

buffer into `pending` rather than publishing at once. The client is opaque, handed straight to each
