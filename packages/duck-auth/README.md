# @gentleduck/auth

Authentication for modern TypeScript apps. Faceted, framework-agnostic, transport-pluggable. Pairs with [`@gentleduck/iam`](../duck-iam) for authorization.

> **Status:** 0.1.0 scaffold. See [`DESIGN.md`](./DESIGN.md) for the full v4.2 spec. Implementation in progress against §22 v1.0.0 scope.

## Quick links

- [`DESIGN.md`](./DESIGN.md) — frozen v4.2 build spec
- [`@gentleduck/iam`](../duck-iam) — authorization companion (RBAC + ABAC)
- [`@gentleduck/iam-auth-bridge`](../iam-auth-bridge) — glue when you want both

## Install

```sh
bun add @gentleduck/auth
```
